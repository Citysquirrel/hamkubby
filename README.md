# 햄쿠비 노래책

한국의 버튜버 그룹, 리스텔라(Listella) 소속 라이버 햄쿠비의 팬사이트입니다.

기존에 운용하고 있는 스프레드시트를 토대로 좀 더 편리한 노래책을 제공하기 위해 제작하였습니다.

본 사이트는 팬사이트임을 알리며, 라이버 및 소속사의 요청에 따라 일부 내용이 변경되거나 서비스가 중단될 수 있습니다.

## 기능

- 라이버가 작성한 스프레드시트의 노래정보를 가져와 리스트업합니다(**공식** 태그).
- 개발자가 직접 작성한 비공식 노래정보를 가져와 리스트업합니다(**비공식** 태그). 해당 노래들은 라이브 방송에서 불렀던 이력이 있는 것들입니다.
- 노래 리스트를 검색 및 필터링할 수 있습니다.
- 원하는 노래를 선택하여 복사하거나 상세 정보를 확인할 수 있습니다.
- 상세 정보는 라이브 방송에서 불렀던 이력, 가사(저작권 문제로 비활성화)를 포함합니다.
- 현재 가사는 새창으로 구글 웹 검색을 통해 제공중입니다.
